# 步骤 1：问题一短期 GPU 需求预测｜实施记忆

> 赛题要求、任务约束及附件字段说明见根目录 [C题_赛题与数据记忆.md](../C题_赛题与数据记忆.md)。本文件只记录预测模型的实施口径与当前结果。

## 1. 预测口径

- 预测目标：`来源区域 × 任务类型 × 到达小时` 的总 GPU 需求，即该单元内所有到达任务 `GPU_Demand` 的总和。
- 预测粒度：6 个来源区域 × 3 类任务，共 18 条小时序列；区域总需求与系统总需求由细粒度预测相加得到。
- 验证：使用 0–2351 小时训练、2352–2375 小时验证；最终测试使用 0–2375 小时训练、2376–2399 小时测试。
- 每个窗口均在预测原点一次性预测后续 24 小时；不使用验证/测试窗口内的真实任务更新模型或构造滞后特征。
- 最终基础调度仍使用 2376–2399 小时实际任务；预测结果仅用于预测评价和容量风险描述。

## 2. 模型与依据

候选模型包括分组历史均值、最近 24/168/336 小时均值、上一日同小时和上一周同小时朴素模型。

已完成的序列诊断表明：GPU 需求在 1、24、168 小时滞后的平均自相关均接近 0；单条序列的小时/周内效应解释率约 1% 或更低；任务计数方差/均值约 0.99。因此不将 LSTM、Transformer 或复杂时序树模型作为主模型。

官方验证集和 48 个训练期滚动 24 小时回测均选择：

```text
direct_mean
D_hat(r,k,t) = mean[D(r,k,τ)], τ ≤ 预测原点
```

这是按“来源区域 × 任务类型”分层的平稳直接需求模型。它直接预测题目所需的小时总 GPU 需求，不把任务数和单任务 GPU 需求作为相互独立的主预测对象。

## 3. 不确定性口径

- 使用完整历史小时任务包的非参数 Bootstrap，进行 10,000 次模拟。
- 每个抽样小时同时保留其全部任务及任务属性，包含任务数、GPU 需求、时长、时延阈值和完成时限；不独立打散任务数与 GPU 属性。
- 分位点根据 48 个训练期滚动 24 小时回测的经验覆盖率校准：区域×类型单元的 80%/95% 区间为 P17–P83、P5–P95；区域和系统汇总的 80%/95% 区间为 P9.5–P90.5、P3–P97。

## 4. 当前结果

### 官方验证窗：2352–2375

| 模型 | WAPE | MAE | RMSE |
|---|---:|---:|---:|
| direct_mean | 72.78% | 23.81 | 45.85 |
| rolling_336 | 72.96% | 23.87 | 45.95 |
| rolling_168 | 73.41% | 24.02 | 45.84 |
| rolling_24 | 76.45% | 25.01 | 46.21 |
| seasonal_weekly | 90.58% | 29.64 | 60.58 |
| seasonal_daily | 109.57% | 35.85 | 69.92 |

### 最终测试窗：2376–2399

- 系统总 GPU 需求 WAPE：**24.30%**；MAE：176.68；RMSE：221.05。
- 18 个细粒度“区域 × 类型 × 小时”单元合并计算的 WAPE 为 65.65%；细粒度误差较高反映任务到达的随机性，区域/系统汇总后存在误差抵消。
- 细粒度单元的 80%/95% 区间覆盖率分别为 78.94%/93.98%；区域与系统汇总的覆盖率分别为 80.36%/93.45%。

## 5. 文件与复现

```text
步骤1_问题一_预测模型/
├─ run_forecast.py                  # 预测、回测、Bootstrap 与图表
├─ forecast_config.json             # 随机种子、窗口与模拟次数
├─ README.md                        # 运行说明
├─ 步骤1_问题一_预测模型_记忆.md      # 本文件
└─ 预测结果/                         # 可复现输出，不纳入 Git
```

运行：

```powershell
cd '步骤1_问题一_预测模型'
python run_forecast.py
```

主要输出：

- `forecast_model_comparison.csv`：官方验证候选模型比较；
- `forecast_rolling_backtest.csv`：48 个滚动预测原点的稳定性比较；
- `forecast_point_results.csv`：18 条细粒度序列的点预测、真实值与区间；
- `forecast_aggregate_results.csv`：区域与系统汇总预测、真实值与区间；
- `forecast_metrics.csv`：区域×类型、区域、系统三层误差指标；
- `forecast_interval_summary.csv`：区间覆盖率与平均宽度；
- `forecast_diagnostics.md` 与 `预测结果/figures/`：文字诊断和图表。
