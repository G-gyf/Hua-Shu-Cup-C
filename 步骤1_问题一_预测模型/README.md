# 步骤 1：问题一短期 GPU 需求预测

运行：

```powershell
python run_forecast.py
```

脚本读取步骤 0 生成的 `fact_tasks.csv`，预测 `来源区域 × 任务类型 × 小时` 的总 GPU 需求。

- 训练/验证：0–2351 训练，2352–2375 验证；
- 最终测试：0–2375 训练，2376–2399 测试；
- 每次都从预测原点一次性预测未来 24 小时，不使用未来真实任务构造特征；
- 点预测在候选模型中按验证集 WAPE 选择；
- 区间由完整历史小时任务包 Bootstrap 得到，保留同一小时全部任务的联合到达结构；
- 区间分位点按训练期滚动回测分别校准：区域×类型单元为 P17–P83 / P5–P95，区域与系统汇总为 P9.5–P90.5 / P3–P97。

输出写入 `预测结果/`，为可复现产物，不纳入 Git。
