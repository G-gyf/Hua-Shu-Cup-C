# 华数杯数学建模竞赛工作区

当前包含 2026 年第七届“华数杯”大学生数学建模竞赛 C 题《面向算电协同的多目标调度优化研究》。

## 目录

- 根目录：赛题 PDF、附件 1、附件数据及 `C题_赛题与数据记忆.md`（赛题背景、要求、约束和数据说明）。
- `步骤0_数据预处理与分析/`：数据预处理与探索分析的实施记录、管道脚本、配置、处理后数据和报告。
- `步骤1_问题一_预测模型/`：问题一短期 GPU 需求预测、回测、Bootstrap 区间与预测结果。
- `格式要求/`：竞赛论文格式、提交说明与 AI 工具使用章程。

## 重建 C 题处理结果

```powershell
cd '步骤0_数据预处理与分析'
python run_pipeline.py
```

原始附件保持不变。命令生成的 `processed/` 与 `reports/` 是可复现产物，因此不纳入 Git 版本控制。
