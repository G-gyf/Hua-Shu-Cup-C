# 华数杯 C 题：面向算电协同的多目标调度优化研究

本仓库用于 2026 年第七届“华数杯”大学生数学建模竞赛 C 题的资料归档、数据准备、模型开发与结果复现。当前已完成赛题与数据梳理、步骤 0 数据预处理与分析，以及问题一的短期 GPU 需求预测。

仓库将“赛题事实与约束”“可复现数据处理”和“各问题模型”分开存放。阅读或继续开发时，请优先以赛题原文和记忆文件为依据；报告中的分析结论均应能回溯到数据或相应脚本。

## 快速复现

### 1. 安装环境

建议使用 Python 3.10 或更高版本。数据处理脚本依赖 `pandas` 与 `openpyxl`；生成图表还需 `matplotlib`。

```powershell
python -m pip install pandas openpyxl matplotlib
```

### 2. 运行步骤 0：数据预处理与分析

必须先运行此步骤，因为后续模型读取其生成的标准化任务事实表。

```powershell
cd '步骤0_数据预处理与分析'
python run_pipeline.py
cd ..
```

该脚本只读取根目录 `附件数据/` 下的官方 Excel 文件，重新生成本目录的 `processed/` 与 `reports/`。具体表结构、检查规则和已发现的数据边界见步骤 0 README 与记忆文件。

### 3. 运行步骤 1：问题一预测模型

```powershell
cd '步骤1_问题一_预测模型'
python run_forecast.py
cd ..
```

脚本读取 `步骤0_数据预处理与分析/processed/fact_tasks.csv`，输出 24 小时预测、候选模型比较、滚动回测、Bootstrap 区间和图表。模型设定、调参与测试结果见问题一 README 和完整报告。

### 4. 运行问题一基础调度

```powershell
cd '步骤1_问题一_预测模型'
python run_basic_schedule.py
cd ..
```

脚本对 2376–2399 的实际到达任务及其携入任务进行分钟级跨小时 MIP 调度。所有任务固定到达即启动，仅优化可行执行区域以最小化最大 GPU 利用率；同时严格检查 GPU、IT 功率、设施功率、单向时延与完成期限。结果写入 `基础调度结果/`；当前单次 MIP 求解最长 1,800 秒，报告会如实标记最优或近优状态及 MIP gap。

## 结果与可复现性说明

- 仓库已保存当前一次运行产生的关键处理表、分析报告、预测结果与图表，便于直接核验论文结论。
- 重新运行步骤 0 或步骤 1 会覆盖对应输出目录中的同名生成文件；若需要保留某次结果，请先复制或以 Git 提交保存版本。
- 所有模型开发均应保持“题目原始数据不改写、测试窗真实值不参与拟合或调参”的边界。赛题定义、约束或单位不明确时，不应以自行推导替代赛题原文。

## 使用约定

- `附件数据/` 是官方输入；不要在其中手工覆盖或编辑数据。
- `processed/`、`reports/`、`预测结果/` 和 `基础调度结果/` 都是脚本生成物，修改口径时应优先修改脚本/配置后重新运行。
- 论文、答题和后续优化模型应引用相对路径的数据表，并记录使用的配置与运行版本。
