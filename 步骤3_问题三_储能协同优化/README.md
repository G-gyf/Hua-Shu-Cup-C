# 问题三：储能协同优化

本目录实现赛题问题三：在附件给定的基准 AI IT 负荷和不可迁移非 AI IT 负荷固定的前提下，优化六个区域的储能充放电、新能源分配及本地电网购售电。

## 边界与口径

- 不重新调度任务，也不使用网络时延或 GPU 迁移决策。
- 不建立跨区输电、潮流、点对点电力交易或跨区碳抵扣。区域仅按自身购售电边界与外部电网交互。
- 当期新能源优先直供本地负荷，售电只允许来自直供后的富余新能源；仅在新能源不足以覆盖本地负荷时允许网电充电；电池放电仅服务本地设施负荷；禁止网电转售和电池外送。
- 碳排只按购电量乘区域碳强度计算；售电不抵扣碳排。
- 储能在 0--2405 小时可运行。2406 小时只进行固定负荷、电网和终端 SOC 结算，禁止充放电。

模型先重算无储能可行基准，再求成本、消纳、低碳、削峰平滑端点，以及基于真实端点成本差的内生 epsilon 候选。不会使用没有数据依据的固定“成本上浮 0.5% / 1.0%”预算。

## 运行

在仓库根目录执行完整问题三前沿：

```powershell
python .\步骤3_问题三_储能协同优化\run_q3_storage.py
```

先做短时功能验证（仅前 48 小时，结果不用于赛题结论）：

```powershell
python .\步骤3_问题三_储能协同优化\run_q3_storage.py --smoke-hours 48 --skip-plots
```

运行售电电价和出口能力敏感性分析：

```powershell
python .\步骤3_问题三_储能协同优化\run_q3_storage.py --include-sensitivity
```

完整运行会在 `储能结果/` 下创建带时间戳的新目录，不覆盖既有结果。敏感性分析需要多次完整线性规划求解，耗时显著增加。
当前机器上一次完整基准前沿（不含敏感性和绘图）约耗时 160 秒。

## 主要输出

- `scenario_summary.csv`：全部端点和 epsilon 候选的 KPI、非支配判定及推荐标签；
- `comparison_to_baseline.csv`：附件基准、无储能反事实和推荐方案比较；
- `region_hour_dispatch_*.csv`：非支配方案逐区域、逐小时储能和电网调度；
- `region_summary_*.csv`、`feasibility_checks.csv`：区域结果与硬约束检查；
- `figures/`：SOC、净购电和策略 KPI 图。
