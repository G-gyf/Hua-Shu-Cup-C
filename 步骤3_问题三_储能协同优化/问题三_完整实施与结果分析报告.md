# 问题三：储能协同优化模型、实施与结果报告

> 运行版本：`run_q3_storage.py`；基准完整运行：`储能结果/run_20260808_231554/`。本报告遵循问题三“给定任务调度和逐时负荷，仅优化储能及电力交互”的边界。所有金额单位为元，功率单位为 MW，能量单位为 MWh，碳排单位为 tCO2。

## 摘要

以附件给定的 AI 基准负荷和非 AI IT 负荷为固定输入，构建六区域、2,407 小时的储能—新能源—电网协同线性规划。模型不重新调度任务，不建立跨区输电；新能源优先服务本地负荷，富余部分可充电、限额外送或弃电，储能只能服务本地负荷。模型输出无储能反事实、经济优先、消纳优先、均衡和电网交换平滑候选，并以 Pareto 支配关系筛选推荐策略。

完整运行表明：固定负荷在本数据中几乎始终可由当地新能源覆盖，经济端点实现零购电、零碳排和 67.93% 新能源利用率。储能的边际作用主要是吸收原本会弃掉的新能源；成本—碳排—正向净购电峰值在此数据下发生退化。电网交换平滑端点虽能将带符号净电网交换的总变差降至接近零，但主要依赖减少售电、增加弃电，不能被表述为储能创造了额外削峰收益。

## 1. 数据依据与问题边界

### 1.1 输入数据

模型只读取步骤 0 的标准化表，不改写官方附件：

| 数据 | 关键字段 | 用途 |
| --- | --- | --- |
| `fact_region_hour_input.csv` | 电价、售电价、碳强度、可再生出力、非 AI IT 负荷 | 逐时能源与电力边界输入 |
| `fact_region_hour_baseline.csv` | `Baseline_AI_IT_Load_MW`、附件基准运行状态 | 固定 AI 负荷与附件对照 |
| `dim_region.csv` | PUE、IT/设施功率上限 | 固定负荷换算和静态校验 |
| `dim_storage.csv` | SOC、功率、效率、购售电上限 | 储能及电网硬约束 |

时域为 0--2406。0--2405 小时允许储能充放电；2406 小时仅结算固定负荷、电网交互和终端 SOC，禁止新充放电。六个区域都具有独立储能与购售电边界；A/B/C 的外送上限为 0，D/E/F 允许有限新能源外送。

### 1.2 明确不纳入的内容

- 不重新安排任务，也不使用 GPU、网络时延、任务迁移或服务等待变量；
- 不建立跨区专线输电、线路潮流、点对点交易、输电损耗或跨区碳结算；
- 不把某一区域售电指定为另一地区的低碳购电；
- 不引入绿证、出口碳信用或售电碳抵扣。

区域售电仅表示向外部电网的本地限额外送，不能被解释为 RegionE 向 RegionD 的直接供电。

## 1. 问题边界

问题三以附件给定的 `Baseline_AI_IT_Load_MW` 和 `NonAI_IT_Load_MW` 为固定输入，不重新安排任务。区域设施负荷为：

\[
L_{r,t}=(Baseline\_AI\_IT\_Load_{r,t}+NonAI\_IT\_Load_{r,t})\times PUE_r.
\]

模型不建立跨区域专线输电、潮流、点对点电力交易或跨区域碳结算。每个区域只依据本地 `MaxGridImport_MW`、`SellLimit_MW`、`MaxGridExport_MW` 与外部电网交互。这与题目未提供跨区线路容量、损耗、结算价格和电能归属数据的边界一致。

## 2. 变量与约束

对每个区域—小时，模型设置新能源直供 \(u\)、新能源充电 \(c^R\)、网电充电 \(c^G\)、储能放电 \(d\)、网电直供 \(g^L\)、新能源售电 \(s\)、弃新能源 \(k\) 和时末 SOC \(e\)。

| 类别 | 变量/参数 | 含义 |
| --- | --- | --- |
| 新能源 | \(u,c^R,s,k\) | 直供、充电、外送与弃电的当期新能源分配 |
| 储能 | \(c^R,c^G,d,e\) | 两类充电、对本地负荷放电及期末 SOC |
| 电网 | \(g^L,G=g^L+c^G\) | 网电直供与总购电功率 |
| 平滑 | \(N=G-s,P,z\) | 净购电、区域正向峰值与相邻时段变化绝对值 |

新能源守恒：

\[
u+c^R+s+k=R.
\]

本地负荷平衡：

\[
u+d+g^L=L.
\]

储能递推：

\[
e_t=e_{t-1}+\eta_c(c^R_t+c^G_t)-d_t/\eta_d.
\]

购电总量为 \(G=g^L+c^G\)，受区域购电上限约束；售电受给定出口上限约束。为排除“放电以腾出新能源售电”的伪套利，模型固定 \(u=\min(L,R)\)，即当期新能源总是优先直供本地负荷；随后才将富余新能源用于充电、售电或弃电。仅当 \(R<L\) 时允许网电充电，因此不会出现“网电充电且新能源外送”的会计套利组合。额外施加 \(d\le L-u\)，使电池仅服务本地负荷。售电位于新能源守恒式中，故只能来自当期富余新能源；网电或电池电量不能转售。

完整硬约束包括：

\[
MinSOC_r\le e_{r,t}\le Capacity_r,
\quad e_{r,2406}\ge InitialSOC_r,
\]

\[
c^R_{r,t}+c^G_{r,t}\le MaxChargePower_r,
\quad d_{r,t}\le MaxDischargePower_r,
\]

\[
G_{r,t}\le MaxGridImport_r,
\quad s_{r,t}\le \min(SellLimit_r,MaxGridExport_r).
\]

此外，全部变量非负；2406 小时固定 \(c^R=c^G=d=0\)、\(e_{2406}=e_{2405}\)。模型还校验固定 IT 和设施负荷不超过给定上限，以及所有时段购电价不低于售电价。

储能在 0--2405 小时运行；2406 小时令充电和放电均为 0，SOC 保持至终端并满足 \(SOC(2406)\ge InitialSOC\)。

## 3. 目标与候选策略

报告成本为购电成本减售电收益，碳排只计算购电：

\[
C=\sum(Gp-sq),\qquad E=\sum(G\cdot CI).
\]

新能源利用率为 \(REU=1-\sum k/\sum R\)。区域峰值净购电为 \(\max_t\max(G-s,0)\)，波动使用相邻小时净购电总变差，另报告标准差。

目标的最小化方向为：净运行成本 \(C\)、碳排 \(E\)、弃新能源 \(K=\sum k\)、归一化区域正向净购电峰值，以及净电网交换总变差 \(TV=\sum|N_t-N_{t-1}|\)。售电收入使净成本可能为负，此时代表售电收入大于购电成本，不代表负能耗或负碳排。

程序依次求经济、消纳、低碳、削峰平滑端点。对消纳和电网友好端点，按实际成本差 \(\Delta C=C_j-C_{econ}\) 构建 \(C\le C_{econ}+\alpha\Delta C\) 的候选，\(\alpha\) 由配置文件给定。该参数描述真实前沿的位置，不是假定的成本预算比例。全部候选经去重和 Pareto 支配筛选后，标记经济、消纳、削峰平滑和均衡推荐方案。

具体求解顺序为：

1. 重算无储能可行反事实；
2. 以词典序分别求经济、消纳、低碳和电网交换平滑端点；
3. 用消纳/平滑端点相对经济端点的实际成本差构造 \(\alpha=0.25,0.50,0.75\) 的内生 ε 候选；
4. 按成本、碳排、弃电、峰值、波动执行去重和 Pareto 支配筛选；
5. 将成本最低、弃电最低、峰值/波动最低及距归一化理想点最近的方案分别标记为经济、消纳、电网交换平滑和均衡推荐。

低碳端点在本次数据中与经济端点指标重复，因此在去重后不单独保留；这是数据特征，而非程序遗漏。

## 4. 售电机制与敏感性

基准方案直接使用附件售电价格和出口上限。敏感性分析通过售电价 \(q^\lambda=\min(\lambda q,p)\) 以及出口能力系数 \(\beta\) 改变外送激励和许可边界，但始终禁止电池外送与网电转售。售电不视为碳抵扣；售电量单独报告。

默认敏感性网格为 \(\lambda\in\{0,0.5,1,1.5\}\)、\(\beta\in\{0,0.5,1\}\)。售电价被限制不超过同小时购电价，避免将题设外推成零售套利价格。2026-08-09 已针对最强外送激励 \((\lambda=1.5,\beta=1)\) 进行完整时域复测，全部物理校验通过。

## 5. 实施步骤与可复现性

1. 读取并合并四张标准化数据表，按区域—小时建立固定设施负荷；
2. 执行静态输入检查：IT/设施功率边界、SOC 初值、价格逻辑、时间和区域覆盖；
3. 构建稀疏 LP：约 13 万连续变量，使用 SciPy/HiGHS 求解；
4. 生成端点、ε 候选、去重后的非支配解和推荐标签；
5. 对每个输出执行新能源守恒、负荷平衡、SOC、功率、购售电、终端状态及并发操作检查；
6. 输出逐时调度、区域汇总、方案汇总、约束检查、对比表和图形。

依赖为 Python 3.10+、`numpy`、`pandas`、`scipy`；绘图另需 `matplotlib`。完整基准前沿在当前机器上约耗时 160 秒。

### 7.1 可行性与求解状态

- 6 个结果对象（5 个优化候选及无储能参考）共执行 84 项逐时/逐类检查，全部通过；
- 最大等式残差为约 \(2.3\times10^{-13}\)，所有 HiGHS 优化调用均以 `Optimal` 状态结束；

- 检查项目包括新能源守恒、本地负荷平衡、SOC 递推与边界、终端 SOC、充放电功率、购售电上限、电池不外送、2406 小时储能静止、同时购售电和同时充放电。

### 7.2 对结果的正确表述

- 附件基准与无储能反事实之间的巨大差异说明：附件运行状态不能被直接当作固定负荷下储能优化的可行最优参照，应仅作为官方给定的对比状态；
- 经济端点相对无储能反事实仅额外减少约 2,112.42 MWh 弃新能源、降低约 8.85 tCO2 碳排，表明储能在本数据下的增量调节空间有限；
- 净成本为负来自 D/E/F 的新能源售电收入。它应被称为“净运行收益”，不可解释为负能耗、负购电或碳抵扣；
- 全部优化候选均为零购电、零碳排，所以不能将成本—碳排关系宣传为一条有效的递进前沿；真正的差异主要是售电收益、弃电、REU 与净电网交换平滑之间的权衡。

电网交换平滑端点的总变差接近 0，但代价是少售电和更多弃新能源；它主要是压低带符号净电网交换，而非额外创造储能削峰价值。因此论文中应将该方案表述为“电网交换平滑—新能源消纳/收益的极端权衡”，不能表述为储能必然带来更强的削峰收益。售电电价与出口能力敏感性分析正是检验这一结论是否稳健的后续步骤。
